# Live retained worker overview

The additive `config/herdr-mods/stellar-retained-overview` source mod reads only the bounded JSON snapshot at `appHome()/stellar-retained-overview.json`. It uses Herdr's documented `readTextFile` API (UTF-8, 1 MiB host ceiling) and GPUI `View.init`, `cx.timer.after`, `cx.notify`, task cancellation, and `View.close` lifecycle surfaces. Refreshes are sequential: the next one-shot timer is scheduled only after the current read finishes. Closing/reloading stops the timer, and a context invalidated by reload ends its loop.

The source exporter `config/hermes-plugins/stellar-herdr/overview_export.py` reuses the merged #366 `overview.snapshot(root, core)` projection. Schema version 1 defines `generated_at` as finite, non-negative Unix seconds (matching #366), `coverage` as a disclosure string, `warnings` as a bounded list, and at most 20 workers. The allowlist carries exact claim/runtime-or-null/incarnation/terminal/source identity, process and task status, plus explicit unverified tests/review/merge fields; it excludes tasks, output and reasoning. Encoded output is limited to 64 KiB and atomically replaced. Missing projection/source, malformed data, write errors or oversized output does not replace the prior file; callers receive an unavailable result. There is no daemon, persistent collector, notification, inference or scheduler in this source slice.

The existing maintained no-agent path is `observer_tick.py`, whose current one-shot operation invokes the existing observation reconcile action. The minimum additive wiring candidate is a second bounded call in that same invocation, after resolving the existing profile settings and `Core`: `export_snapshot(profile_root, core, Path(settings['overview_snapshot']))`, where `overview_snapshot` is configured to the same app-home file the mod reads. It must remain one-shot, silent on stdout, return the existing `wakeAgent:false` sentinel, and perform no inference. This issue adds the callable exporter but does not edit the maintained tick script, settings, installed files, or create a schedule. PR #366's frozen reviewed head `dfedcdfbef6ed85b71f1b85011fd469b8e3e67c2` is now merged at develop `adc887ff604aeb64f4caaf09b8361c43bcdaf369`; combined qualification uses its exact producer interface. No operator installation or activation is implied.

Coverage is limited to confirmed receipt-backed Stellar launches. Missing records are not an all-clear. A process exit code, including zero, does not prove tests, independent review, merge or completion. Private tasks, terminal logs and reasoning are excluded. The Herdr app reads the snapshot; it does not read a worker transcript or run commands. Headless rendering cannot establish native desktop focus or foreground acceptance.

With the native mod installed and `overview_snapshot` set to its app-home snapshot file, `stellar_herdr show` and `focus` accept an explicit issue number. They prefer a matching live pane, or a focusable finished pane. When neither is available, they open the existing retained overlay with only the requested issue's confirmed attempts. The tool returns an instance-bound receipt when the mod constructs the requested view. Current visibility and compositor output require their own app readback. The scoped view is a point-in-time snapshot with freshness information and a Close control. Opening the mod normally still shows the combined live snapshot.

The mod is source-only; it is not installed, and no runtime, layout, schedule or app restart was performed.

The isolated headless test resolves the declared `@playwright/test` dependency from this repository's normal Node module resolution. On a host where repository dependencies are not installed, the fixture may be run with `STELLAR_OVERVIEW_PLAYWRIGHT_ROOT` explicitly set to an existing local checkout containing that dependency (for example the read-only issue352 checkout used during development); this is a test-only module-resolution override, not a product dependency or installation step.
