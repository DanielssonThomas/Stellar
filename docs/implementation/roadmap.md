# Implementation roadmap

GitHub Issues and the [Stellar Development project](https://github.com/users/DanielssonThomas/projects/2) are the canonical backlog. The [foundation Epic](https://github.com/DanielssonThomas/Stellar/issues/1) tracks child work; issue labels and relationships hold task status and dependencies.

## Bootstrap boundary

The local Nx/Angular vertical slice, shared atom, tests, issue/commit policies, documentation governance, and CI workflow are implemented and locally verified. Remote branch protection and CI execution are pending the first push. Hermes orchestration and unattended releases remain out of scope.
