# Built-in generation prompt specifications

All six cutouts used the built-in `imagegen` tool with `transparent_background: true`, one request per meaningful layer. Each request referenced `master-guide-v1.png`; the primary hair requests also referenced their corresponding generated body. Six initial edit calls succeeded; no targeted correction calls or external API were used. These are the final prompt specifications; positional requests were guidance, and the actual registration is recorded separately in `../registration.json`.
