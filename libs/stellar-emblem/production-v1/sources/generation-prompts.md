# Built-in generation prompt specifications

All six cutouts used the built-in `imagegen` tool with `transparent_background: true`, one request per meaningful layer. Each request referenced `master-guide-v1.png`; the primary hair requests also referenced their corresponding generated body. Six initial edit calls succeeded; no targeted correction calls or external API were used. These are the final prompt specifications; positional requests were guidance, and the actual registration is recorded separately in `../registration.json`.

## Leaf segmentation maps (experiment #251)

Built-in ImageGen edit mode produced `gold-ornament-segmentation-v2.png` and `violet-ornament-segmentation-v2.png` from the untouched, unregistered ornament cutouts. The exporter applies the original registration to each map, grows labels through the original visible ornament from each label's largest interior core, then assigns the remaining fringe. This keeps neighboring outlines with their leaves and preserves every source pixel. The gold ornament yields fourteen leaf regions and one whole gem/setting; violet yields six leaf regions and one whole gem/setting. `previews/leaf-contact-sheet.png` shows the actual exports.

## Strand segmentation maps (experiment #251)

Built-in ImageGen edit mode produced `gold-hair-segmentation-v2.png` and `violet-hair-segmentation-v2.png` from the corresponding registered `layers/*-hair.png`. Outputs were 1254 square and are sampled at 1280 square by the deterministic exporter. These are segmentation labels, not replacement artwork. Preserve the original hair pixels; approximate authored labels can drift slightly from the source silhouette, so uncovered areas take the nearest label. No fallback CLI/API was used.

Prompt set: use this exact prompt twice, substituting GOLD and VIOLET for COLOR and the corresponding registered hair PNG as edit target:

Edit target is a registered 1280 x1280 COLOR flowing hair cutout, shown in the supplied image. Create a PRECISE FLAT SEGMENTATION MAP, NOT a new hairstyle. Preserve the EXACT canvas, placement, scale, silhouette and all curl positions. Trace the visible long curving hair LOCKS into 12 separate flat-colored regions. Each colored region should be a complete organically curved strand/lock or curl clump, following the existing dark valleys between strands; no straight horizontal bands, geometric tiles or rectangular cuts. Use twelve solid clearly distinct flat label colors: red #ff3030, orange #ff9020, yellow #ffff20, lime #80ff20, green #10b040, cyan #20ffff, blue #2040ff, violet #9030ff, magenta #ff20d0, pink #ff90b0, white #ffffff, brown #804020. No shading, highlights, gradients, texture, glow, text or outlines: just 12 labeled flat organic hair regions tessellating the EXACT existing hair silhouette, black background outside the hair. This is a technical segmentation mask used to separate the original artwork into natural long flowing curved locks without repainting it. Pay attention to crown strands radiating from the part and long S-shaped lower curls. Each region must flow ALONG a strand from root toward tapered end, never across it. Keep all silhouette tips and curls exactly registered.
